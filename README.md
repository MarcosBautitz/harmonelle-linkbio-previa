# Harmonelle · link da bio · prévia para aprovação

Página única do link da bio do Instagram da Clínica Harmonelle, Dra. Manu Maia,
Biomédica Esteta, CRBM-5 015437, em Blumenau, SC.

**Este repositório existe só para a cliente aprovar a peça pelo celular.**
O endereço definitivo é `harmonelle.com.br/linkbio`, e é para lá que a página
vai depois do aceite.

Existe uma versão só, na raiz:

https://marcosbautitz.github.io/harmonelle-linkbio-previa/

O `index.html` é autossuficiente: as fotos estão embutidas no próprio arquivo,
em base64. A página não é indexada pelo Google, por causa da meta `robots`.

que estava em `novodesign/` assumiu a raiz. A pasta `novodesign/` deixou de
existir. No mesmo dia, o horário de segunda a sexta passou a ser 8h às 19h.

Depois da aprovação, este repositório pode ser apagado.
